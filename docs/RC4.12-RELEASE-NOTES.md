# WePlay rc4.12 für Windows

- **LAN und private Interneträume.** WePlay aktualisiert die Windows-Netzfilter der Spielkopie auf explizite IPv4- und IPv6-Adressgrenzen. Damit korrigiert rc4.12 die Filterregeln für den Spielstart in Stufe 11. Loopback bleibt für die lokalen WePlay-Dienste erreichbar.
- **Launcher-Update.** Ist Siedler 7 noch geöffnet, sagt der Launcher jetzt direkt, dass das Spiel vor der Installation geschlossen werden muss.

Aktualisiere über den Launcher oder über `Setup.exe`. Wähle anschließend bei Bedarf **Aktualisieren / reparieren**, um die vorhandene Spielkopie samt Spielständen und Einstellungen zu übernehmen.

## English

- **LAN and private internet rooms.** WePlay updates the game copy’s Windows network filters to use explicit IPv4 and IPv6 address boundaries. This corrects the isolation rules used during startup stage 11. Loopback remains available for local WePlay services.
- **Launcher updates.** If Settlers 7 is still open, the launcher now asks you to close the game before installing the update.

Update from the launcher or run `Setup.exe`. If prompted, choose **Update / repair** to carry over your existing game copy, saves and settings.
