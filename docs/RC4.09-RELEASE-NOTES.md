# WePlay rc4.09 für Windows / for Windows

- **Genauere Diagnose beim Mehrspielerstart.** Scheitert die Windows-Netzisolationsprüfung (Startstufe 11) beim Start über LAN oder beim Öffnen eines privaten Internetraums, erfasst `S7-Diagnose.json` den ersten fehlgeschlagenen Socket-Test, den konkreten Aufruf und den verfügbaren Winsock-Code. Den Bericht kannst du über **Hilfe** oder direkt in der **Einrichtung** speichern.

- **More detailed multiplayer startup diagnostics.** If the Windows network isolation check (startup stage 11) fails when starting LAN play or opening a private internet room, `S7-Diagnose.json` records the first failed socket test, the operation and the Winsock code when available. Save the report from **Help** or directly from **Setup**.
