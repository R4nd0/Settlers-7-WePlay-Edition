# WePlay rc4.07 für Windows / for Windows

- **Erweiterter Diagnosebericht:** `S7-Diagnose.json` enthält bis zu 32 relevante Launcher-Vorgänge mit Zeitstempel, letzter Phase, Warnungen, Fehlercodes und verfügbaren Windows- und Prozess-Exitcodes. Der Verlauf bleibt über Launcher-Neustarts hinweg erhalten.
- **Export bei Fehlern:** Der Bericht lässt sich unter **Hilfe** oder direkt in der **Einrichtung** speichern. Wenn der Hintergrundprozess nicht startet, exportiert der Launcher den bereits erfassten Verlauf.
- **Fehlermeldungen:** Der Launcher zeigt den Fehlercode und verweist auf den Diagnoseexport. Rohprotokolle, lokale Pfade, Spielernamen, IP-Adressen, Einladungen und Spielstände sind vom Export ausgeschlossen.

- **Expanded diagnostic report:** `S7-Diagnose.json` includes up to 32 relevant launcher operations with timestamps, the last phase, warnings, error codes, and available Windows and process exit codes. The history survives launcher restarts.
- **Export after failures:** Save a report from **Help** or directly from **Setup**. If the backend fails to start, the launcher exports the history it has already recorded.
- **Error messages:** The launcher shows an error code and points to the diagnostic export. The export excludes raw logs, local paths, player names, IP addresses, invitations, and saves.
