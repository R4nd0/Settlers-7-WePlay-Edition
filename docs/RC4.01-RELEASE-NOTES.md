# WePlay RC4.01

RC4.01 behebt ein Problem beim Aktualisieren und Reparieren tief verschachtelter WePlay-Kopien. Meldet die Einrichtung einen zu langen Pfad, wähle über **Ändern…** einen Speicherort näher am Laufwerksanfang. WePlay übernimmt Spielstände und Einstellungen in die neue Kopie. Ein Standalone-Export mit externem Spielordner bleibt an diesen Speicherort gebunden.

**Hilfe / Diagnose** ist direkt in der Einrichtung erreichbar. Nach einem Abbruch zeigt der Launcher dort die Fehlerdetails an.

RC4.01 fixes an upgrade and repair issue with WePlay copies stored in deeply nested folders. If setup reports that the path is too long, select **Change…** and choose a location closer to the drive root. WePlay transfers saves and settings to the new copy. A standalone export with external game storage stays linked to that location.

**Help / diagnostics** is available directly from setup and displays the details when setup stops.
