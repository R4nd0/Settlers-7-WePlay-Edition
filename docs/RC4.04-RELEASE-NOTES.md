# WePlay rc4.04

Unter **Grafik → Grafikpipeline** stehen für Gold und beide History-Ausgaben vier Windows-Renderer zur Wahl. DXVK 3.1.1 bleibt Standard. DXVK-Async 1.10.3 unterstützt ältere Vulkan-1.1-Treiber. DXVK-GPLAsync 2.6.2-1 bietet einen alternativen Vulkan-1.3-Pfad. Natives D3D9 verwendet den Windows-Renderer ohne Vulkan. Die Auswahl gilt ab dem nächsten Spielstart.

Under **Graphics → Graphics pipeline**, Gold and both History editions offer four Windows renderers. DXVK 3.1.1 remains the default. DXVK-Async 1.10.3 supports older Vulkan 1.1 drivers. DXVK-GPLAsync 2.6.2-1 provides an alternative Vulkan 1.3 path. Native D3D9 uses the Windows renderer without Vulkan. The selection takes effect the next time the game starts.
