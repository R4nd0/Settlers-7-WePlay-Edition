# WePlay rc4.03

Die Grafikprüfung ist optional. WePlay installiert und repariert Kopien auch dann, wenn keine GPU bestätigt wurde. Beim Spielstart versucht DXVK mit der Einstellung **Automatisch**, selbst eine geeignete GPU zu wählen. Die Grafikprüfung bleibt für die Diagnose verfügbar.

The graphics check is optional. WePlay installs and repairs copies even if the check could not confirm a GPU. At game start, DXVK can select a suitable GPU with the **Automatic** setting. The graphics check remains available for diagnostics.
