# WePlay rc4.05 für Windows / for Windows

- **LAN-Start:** WePlay wartet kurz und versucht es automatisch erneut, wenn der Port für die LAN-Suche noch vom vorherigen Start belegt ist. Fehlermeldungen unterscheiden jetzt zwischen Suchport, Netzwerkadapter und lokalem LAN-Dienst.
- **Windows-Netzwerkfreigaben:** Die Einrichtung bietet Netzisolation und, für beide History-Ausgaben, privaten LAN-Zugriff an. WePlay merkt sich die Auswahl für spätere Reparaturen.
- **ReShade Maximum:** Die Beleuchtung verwendet das aktuelle Bild. Die Schärfung wurde entfernt, und Bloom ist auf breitere helle Flächen begrenzt. Das reduziert Doppelkonturen und Säume an Menütext. SMAA bleibt separat wählbar.

- **LAN startup:** WePlay waits briefly and retries when the discovery port is still in use after a previous launch. Error messages now distinguish between the discovery port, network adapter and local LAN service.
- **Windows network permissions:** Setup offers network isolation and, for both History editions, private LAN access. WePlay remembers the choice for later repairs.
- **ReShade Maximum:** Lighting uses the current frame. Sharpening was removed, and bloom is limited to broader highlights. This reduces trails and halos around menu text. SMAA remains a separate option.
